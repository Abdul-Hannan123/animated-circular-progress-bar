# ⭕ Animated Circular Progress Bar

A simple and interactive **Animated Circular Progress Bar** built using **HTML, CSS, and JavaScript**.

When the page is loaded or refreshed, the progress bar starts from the beginning and smoothly animates until it reaches the defined target percentage.

---

## ✨ Features

- ⭕ **Circular progress bar**
- 🎬 **Smooth loading animation**
- 📊 Displays the current **percentage**
- 🔄 Animation starts automatically on page reload
- 🎯 Stops at the defined target percentage
- 🎨 Clean and modern UI
- 📱 Responsive design
- ⚡ Built with Vanilla JavaScript
- 🚫 No external libraries required

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**

---

## ⚙️ How It Works

The circular progress bar has a predefined **target percentage**.

When the page loads:

1. The progress starts from **0%**.
2. JavaScript gradually increases the percentage.
3. The circular progress indicator moves according to the percentage.
4. The number displayed in the center updates at the same time.
5. The animation stops when it reaches the **target percentage**.

For example, if the target value is **52%**, the animation will smoothly move:

```text
0% → 1% → 2% → 3% → ... → 52%
